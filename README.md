# Cold Ember

Projeto Introdução ao Unity (Tutorial), da disciplina Jogos Digitais (Insper).

Você é uma brasa presa numa cripta de gelo. Junte os 5 fragmentos de chama e volte à fogueira antes que o calor acabe.

**Jogar no navegador:** _link do itch.io_

## Controles

| Ação | Teclado | Controle Xbox |
| --- | --- | --- |
| Mover | WASD / setas | Analógico / D-pad |
| Dash | Espaço / Shift | A / RT |
| Pausar | Esc / P | Start |
